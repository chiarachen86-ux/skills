# 版式锁定及整组技术检查

## 固定版式
陶瓷挂饰可沿用assets/ceramic-ornament/layout.json及同目录四张已审核基准。它们不是新批成品；原图、姓名、风格和标题必须替换为本批内容。其他产品只用相应本批确认版式，不读陶瓷资产。

同一版式先锁定背景/轮廓/孔位/挂绳/标签/标尺区域，再编辑印花及姓名。layout.json的circle_bbox是已审核正面几何；artwork_target_bbox与name_target_bbox是为最新姓名规则新划分的目标区，首套须视觉验证，不冒称旧字体已更新。完整图形（含花环、雪地）等比适配图形区，姓名居中在下方独立区。尺寸和分辨率变化时只等比换算坐标；不同视角、产品形态、页选项数量须建立新布局，不生搬硬套四款版。

提供参考图及坐标约束交给图像工具；遵守图像工具限制。需要程序合成或几何校正时依用户明确授权，本次已授权准备可复用模板，但不自动重做已有成品。模板hash变更时重新核实。检查实际生成轮廓，不能用JSON宽高相等代替实际成品为圆形的检查。

## 一次完成技术检查
每组输出保存后，建立显式JSON清单（数组，每项path及可选sha256），只列本次成品，核对清单是否与计划模块/数量一致，再执行：

```sh
python3 <skill-dir>/scripts/check_suite.py <manifest.json> --report <report.json>
```

脚本一次读取每个PNG，核对CRC、像素流完整性、实际宽高、方形、2000像素最低标准、色彩标签、文件hash及重复输出路径；不修改任何图片。明确获本批低分辨率例外时才用--min-pixels指定，报告仍记录实际像素。ICC存在不等于已确认sRGB，报告区分ICC及sRGB声明。默认退出码1表示有技术失败，报告给出逐项原因；不可改状态掩盖失败。

技术检查后逐图视觉检查只聚焦内容：文字/姓名及字体、完整印花、宠物毛色与实宠、外形/材质、手部遮挡和透视、风格、编号及页数。技术脚本的visual_review永远是pending，不会自动批准。仅变更图重做对应检查，最终复核全批计划清单与实际交付、云端回读。

## 依赖与限制
检查脚本只用Python标准库，不依赖Pillow。固定资产不含Brittany Signature字体；精确排字尚须用户可用字体资源，缺少时按主技能记录视觉匹配限制，不宣称已精确验证。历史规则在references/history中保留，仅追溯旧批时读取，不参与新批产品路由。
