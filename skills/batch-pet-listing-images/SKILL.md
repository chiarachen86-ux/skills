# 文件夹批量出图

1. 定位用户指定的文件夹，记录原文件夹标识作为写回目标。若未指定且上下文无法确定，询问文件夹名称或链接。一次列全该文件夹直属文件，按文件名自然排序，固定本批输入清单。逐张查看原图，排除模板、场景成品、选择图及以往导出；保留原文件。区分同一款式的圣诞版和日常版、不同毛色和不同品种，避免把同款的多个视图当成多个毛色。
2. 每次执行时，按名称找到并读取当前安装的 replace-pet-air-freshener-suite（全套图）和 create-pet-breed-choices（品种选择图），按本次产品读取它们当前引用的模板、颜色表及对应要求。不要沿用上次运行缓存的模板。若缺少关键依赖，说明受影响的交付项。
3. 每个同品种同产品组只排一套全套图。遵循用户指定的首图款式和模板配对，其他独立场景依原图顺序轮换款式，优先展示尚未出现的毛色；同一场景内的实宠、产品和对应印刷图一致。需要正反面或两种风格对照时使用对应配对。场景少于款式时，保留模板数量，通过选择图展示全部款式。
4. 将该组所有款式原图一起交给最新版品种选择图技能，生成一组完整的选择图。全套图流程中若已有同用途的选择图步骤，在该步骤调用品种选择图技能一次，结合产品专属模板和当前毛色、排序、分页规则；其他用途的风格对照图仍按全套图要求生成。逐项核对编号、毛色、图文配对和款式总数。
5. 将实际生成的图片按对应技能的成品名称直接保存至步骤 1 的原文件夹。涉及多个组时用组名区分同名成品；与既有文件冲突时保留原文件并为新成品加版本后缀。按下游技能要求打包时，单张成品也须保存。逐个核实文件所在文件夹、可读取性和数量，给出成品入口；局部失败时保留已完成图片，重试缺项并如实报告结果。
