# 品种选择图

制作时读取并执行 [选择页规则](../replace-pet-air-freshener-suite/references/choices.md)，按风格读取套图技能 assets 中的两张模板：圣诞帽使用 品种选择固定模板.png，日常花环使用 品种选择固定模板-日常花环.png。单独调用时选项来自本次用户上传或明确指定的源图；通过全套图调用时遵循对应文件夹原图来源规则。

先按实际风格分组，每种风格1至8个选项放在同一页，超过8个才在该风格内分页，不混合风格。同一宠物的圣诞版和日常版分别保留，不合并。例如8张圣诞加8张日常输出2页，每页8项，8项采用4×2布局。组内保留输入顺序，跨页连续编号，保留原图姓名及其他文字。其他识别、版式、检查与交付要求以链接规则为准。仅修改技能时不生成成品。
